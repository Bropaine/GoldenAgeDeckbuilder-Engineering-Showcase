# Conceptual engineering diagrams

[Back to showcase](../README.md)

These diagrams explain responsibilities and boundaries. They are authored summaries, not exact class diagrams, serialized schemas, or generated source dependency graphs. Each page includes a text explanation as well as Mermaid markup.

- [State lifetimes](STATE_LIFETIMES.md): reusable definitions, persistent copies, and fresh Battle state.
- [Combat command flow](COMBAT_COMMAND_FLOW.md): validation, authoritative work, and feedback.
- [Restore flow](RESTORE_FLOW.md): candidate construction before live installation.
- [Engineering workflow](ENGINEERING_WORKFLOW.md): decisions, bounded implementation, evidence, and acceptance.

The diagrams use the project's paper, ink, navy, and gold visual vocabulary. They depict no private source paths, exact APIs, asset identifiers, or save fields.
